components of a computer

  • input unit

    • Used to enter data and instructions.
    • Examples: Keyboard, mouse, scanner, microphone.

  • CPU(Central Processing Unit)

    • The brain of the computer. It processes instructions.
    • ALU - Performs arithmetic and logical operations.
    • CU(Control Unit) - Controls and coordinates computer operations.
    • Registers - Temporarily hold data and instructions during processing.

  • memory unit

    • Stores data and instructions.
    • Primary memory: RAM, ROM
    • Secondary memory: HDD, SSD, pen drive

  • output unit

    • Displays the processed information.
    • Examples: Monitor, printer, speakers.
